# Using Insights

This guide is for owners and operators who read performance numbers. Every step uses the labels you see on screen.

## What you're looking at

| Screen or signal | What it tells you |
| --- | --- |
| **Insights** | Your key performance metrics |
| A **Metric** | One measure of how the site or content performs |
| A trend over time | Whether things are improving or declining |

## What to do when...

| Situation | What to do |
| --- | --- |
| A metric is unfamiliar | Note what it measures before acting on it |
| A number drops suddenly | Look for a recent change that could explain it |
| You want to improve a page | Use the metrics to pick the pages with the most room to grow |
| Old data is missing | It may have aged out past the retention period |

## Settings and retention

- Set the **retention** period for how long data is kept.
- Judge performance on trends across days or weeks, not a single number.
